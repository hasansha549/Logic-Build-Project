<h1>JavaScript Quiz App</h1>
A responsive MCQ Quiz Application built with HTML, CSS, and JavaScript. This project demonstrates interactive quiz functionality, answer validation, countdown timers, and score tracking.
Features
• 📝 Multiple-choice questions (MCQ)
• ⏱️ 15-second countdown timer for each question
• ✅ Correct answers are highlighted in green
• ❌ Incorrect answers are highlighted in red
• 📊 Automatic score calculation
• 🏆 Final score and highest score display
• 🔄 Restart Quiz functionality
• 🎯 Interactive question-by-question navigation
• 📱 Clean and responsive user interface
Technologies Used
• HTML5 — Structure and semantic markup
• CSS3 — Styling, layout, and responsive design
• JavaScript (ES6+) — Quiz logic, timer, DOM manipulation, event handling, answer validation, and score management
Learning Focus
This project was created to strengthen practical knowledge of JavaScript DOM manipulation, event listeners, conditional logic, timers, arrays, functions, and dynamic UI updates.

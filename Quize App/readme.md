<h1>JavaScript Quiz App</h1>
A responsive MCQ Quiz Application built with HTML, CSS, and JavaScript. This project demonstrates interactive quiz functionality, answer validation, countdown timers, and score tracking. <br>
Features <br>
• 📝 Multiple-choice questions (MCQ)<br>
• ⏱️ 15-second countdown timer for each question<br>
• ✅ Correct answers are highlighted in green<br>
• ❌ Incorrect answers are highlighted in red<br>
• 📊 Automatic score calculation<br>
• 🏆 Final score and highest score display<br>
• 🔄 Restart Quiz functionality<br>
• 🎯 Interactive question-by-question navigation<br>
• 📱 Clean and responsive user interface
Technologies Used<br>
• HTML5 — Structure and semantic markup<br>
• CSS3 — Styling, layout, and responsive design<br>
• JavaScript (ES6+) — Quiz logic, timer, DOM manipulation, event handling, answer validation, and score management
Learning Focus<br>
This project was created to strengthen practical knowledge of JavaScript DOM manipulation, event listeners, conditional logic, timers, arrays, functions, and dynamic UI updates.
